# Blogging Website  

A fully functional **Blogging Website** where users can create, update, and read blogs. This project integrates both front-end and back-end technologies to provide a seamless user experience. Authentication is handled via **Firebase**, and the back-end is built with **MongoDB** and **Express.js**.  

# Live Website: https://blog-sphere-64805.web.app/
---

## Features  

### 1. **Authentication System**  
- Users can register and log in securely using **Firebase Authentication**.  
- Protected routes for authenticated users.  

### 2. **Blog Management (CRUD)**  
- **Create**: Users can post a new blog.  
- **Read**: View all blogs with detailed descriptions.  
- **Update**: Edit blogs authored by the user.  
- **Delete**: Delete their own blogs.  

### 3. **Comment System**  
- Users can comment on other users' blogs.  
- Restrictions: Users cannot comment on their own posts.  

### 4. **Wishlist Functionality**  
- Users can add blogs to their personal wishlist for later viewing. They also can remove the blog from their wishlist collection.  

### 5. **Slider Integration**  
- A visually appealing slider is used to showcase featured posts.  

### 6. **Real-Time Toast Notifications**  
- **React Toastify** is used to show notifications for actions like adding to wishlist, posting a comment, and errors.  

### 7. **Modern UI Design**  
- Styled using **Tailwind CSS**, **DaisyUI**, and **React Icons** for an elegant and responsive user interface.  

### 8. **Axios for API Calls**  
- Simplified communication between the front-end and back-end using **Axios**.  

### 9. **Backend API**  
- Built with **MongoDB** and **Express.js**.  
- Provides endpoints for blog management, user-specific data retrieval, and more.
